# **App Name**: AquaLink

## Core Features:

- Fish Photo Capture: Seller captures photos of available fish using the app's camera interface.
- Listing Creation: Seller creates listings with fish photos and contact information (phone number).
- Real-time Updates: Listings are updated in real-time, visible to customers as soon as they're posted by the seller.
- Customer View: Customers can browse listed fish photos with seller details.
- Seller Contact: Clicking seller's number redirects to phone dial with pre-filled number.

## Style Guidelines:

- Primary color: Ocean Blue (#3498DB) to evoke freshness and sea.
- Background color: Light gray (#ECF0F1) to provide a clean and neutral backdrop.
- Accent color: Sea Green (#2ECC71) to highlight important elements.
- Font: 'PT Sans', a humanist sans-serif for headlines or body text, for readability and a modern feel.
- Use clear and relevant icons for fish categories and seller actions.
- Grid-based layout to display fish photos uniformly and cleanly.
- Subtle transitions and loading animations to improve user experience.
